Path of Exile

Build Optimizer

Le moteur cherche un build complet (stuff, gems, flasks, tree, jewels) et le score avec le vrai Path of Building. Pas une formule maison.

GitHub Pages n’exécute pas le moteur. PoB et LuaJIT tournent sur ta machine. Cette page est la vitrine ; l’optimiseur s’ouvre en local.

Lancer

git clone --recurse-submodules https://github.com/Vivosjerome/PathOfExileBuilder.git
cd PathOfExileBuilder
.\scripts\run-worker.ps1 ui

Puis ouvre http://127.0.0.1:8765/ — classe, skill, crit, res, vie, ES, et le reste.

Prérequis

LuaJIT dans tools/luajit/, Python 3, et le sous-module Path of Building Community.
