Path of Exile

Build Optimizer

Le moteur cherche un build complet (stuff, gems, flasks, tree, jewels) et le score avec le vrai Path of Building. Pas une formule maison.

Le calcul PoB ne tourne pas dans le navigateur. GitHub Pages affiche l’interface. Un clic ouvre une issue ; GitHub Actions exécute LuaJIT + Path of Building, puis republie le résultat ici. Le repo doit être public, et Pages (Settings) doit utiliser la source GitHub Actions.

Ouvrir l’optimiseur

Comment ça marche

1. Remplis crit / res / vie / ES / skill.
2. « Lancer sur GitHub » → crée l’issue (tu dois être le propriétaire du repo).
3. Actions tourne PoB (quelques secondes en test dry-run, 20–50 min en recherche complète).
4. Recharge l’optimiseur : le dernier build est dans Résultats.

En local (plus fluide)

git clone --recurse-submodules https://github.com/Vivosjerome/PathOfExileBuilder.git
cd PathOfExileBuilder
.\scripts\run-worker.ps1 ui

Prérequis

LuaJIT dans tools/luajit/, Python 3, et le sous-module Path of Building Community.
